Phase 2 — Exploration

Google Sheets — Architecture analytique

Avant Tableau, Google Sheets a servi de couche d'exploration avec 7 onglets, des formules dynamiques reférençant les 5 000 lignes sources, et plusieurs TCD.

📋
Dashboard 1 — Pipeline Overview
SUMIF · COUNTIF · VLOOKUP
KPIs globaux, pipeline par stage avec probabilité VLOOKUP depuis table Reference, At-Risk deals (Contract_Value >$300k ET Probability <30%).
🌍
Dashboard 2 — Performance Drivers
SUMIFS · AVERAGEIF · Color Scales
Pipeline par Région × Industry × Canal. Heatmap Region × Industry avec color scale gradient pour identifier les combinaisons les plus génératrices.
👤
Dashboard 3 — Reps & Forecast
TCD · Win Rate ratio · IFERROR
Top 10 commerciaux, Win Rate calculé en colonne adjacente au TCD (ratio non natif), Forecast Accuracy par catégorie, impact concurrence sur les pertes.
⚙️
Architecture multi-onglets
Table Reference · Raw Data immuable
Onglet Raw Data jamais modifié, table Reference centralisée pour les VLOOKUP, recalcul automatique de toutes les analyses à chaque modification source.

Phase 3 — Tableau

Calculated Fields & LOD Expressions

Au-delà des visualisations, les calculs métier développés dans Tableau attestent d'un usage avancé — notamment les LOD expressions imbriquées (FIXED dans FIXED), signature d'une maîtrise avancée de l'outil.

⚡ Calculated Fields clés
[Win Rate]
SUM(IF [Stage]="Closed Won" THEN 1 ELSE 0 END) / (SUM(IF [Stage]="Closed Won" THEN 1 ELSE 0 END) + SUM(IF [Stage]="Closed Lost" THEN 1 ELSE 0 END))
[Best Win Rate] — LOD imbriqué
{FIXED : MAX( {FIXED [Sales Rep Name] : [Win Rate]} )}
[Deals Critiques] — filtre métier
SUM(IF [Contract Value] > 400000 AND [Probability] <= 30 AND [Status] = "Open" THEN 1 ELSE 0 END)
[Top Rep Pipeline] — LOD imbriqué
{FIXED : MAX( {FIXED [Sales Rep Name] : SUM([Contract Value])} )}

Contexte

Pourquoi ce projet ?

Dans mon alternance, je travaille quotidiennement sur des problématiques Revenue Operations et Sales Analytics avec Salesforce comme outil principal. Manipuler de la donnée commerciale, construire des rapports pipeline, suivre la performance des équipes Sales — c'est mon terrain de jeu professionnel.

Le problème : les données réelles de mon entreprise sont strictement confidentielles. Impossible de les exposer dans un portfolio public, même partiellement anonymisées.

La solution : dataset synthétique reproduisant fidèlement la structure d'un export Salesforce — 5 000 deals, 21 colonnes, données réalistes couvrant 24 mois d'activité commerciale, avec toute la complexité d'un pipeline B2B SaaS multi-régions.

Chaque analyse, chaque formule, chaque visualisation produite ici est directement transposable à un environnement professionnel réel.
